01

The Proposer/Authority Split

Aukora segregates the workspace into two distinct spaces: an isolated, sandboxed Proposer Layer (where the AI model runs and suggests changes) and the Authority Kernel. An agent can never execute files directly.

02

The Aumlok Signature Barrier

No action can pass the chokepoint unless it is cryptographically signed by your local Aumlok Ed25519 key — a real algorithm, human-held, generated and kept in your own terminal (not production hardware/HSM custody today). The user holds absolute command over local file writes and terminal invocations.

03

Hash-Chained Receipts

Workbench and kernel actions commit a hash-chained receipt record. This builds an append-only, tamper-evident history of the code changes, so silent or undetected drift is always visible after the fact.
