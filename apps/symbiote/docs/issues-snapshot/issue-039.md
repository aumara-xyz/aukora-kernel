## Body

## Why this exists
Auma's longer replies have been cut off mid-sentence. Silent truncation makes a partial answer look complete and hurts spec-writing and review.

## Goal
Make chat response truncation explicit and support longer structured replies.

## Proposed behavior
- Raise the chat-lane output token allowance to a reasonable spec-writing size where supported.
- If a response still hits the cap, show a visible truncation marker in the transcript.
- Optional later: continuation flow that can request/merge the rest of a capped response.

## Candidate tests
- With an artificially low cap, response displays a truncation marker.
- Normal responses do not display the marker.
- The marker is visible in the UI transcript and/or API response metadata.
