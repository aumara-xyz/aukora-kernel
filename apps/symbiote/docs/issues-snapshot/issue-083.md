- committed
- finalized
- reverted
- quarantined

- Aukora prefix
- marker file
- matching receipt/capability/session id
- no raw arbitrary /tmp deletion

- crash between reserve and finalize leaves recoverable/quarantined state
- rollback_sandbox refuses arbitrary /tmp path
- rollback_sandbox accepts only marked/tokened Aukora sandbox
- receipts report pending/committed/finalized/reverted/quarantined honestly.
