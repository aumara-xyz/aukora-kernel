Any model that correctly followed the prompt's own format could never parse. This likely means the Fusion council has never successfully parsed a real, prompt-compliant model response before this fix, in the entire time this engine has existed. Fixed with a real live-run-captured regression test; confirmed fail-before/pass-after against both the unit test and a second live council run (0/5 models parsed before the fix, 1-2/5 after — remaining non-votes are separate per-model format issues, not this bug).
