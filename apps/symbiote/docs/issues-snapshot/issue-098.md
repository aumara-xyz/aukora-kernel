## Summary
Built a throwaway sandbox prototype of the **Weave Sync Packet** node-to-node advisory comms protocol (signed glyph + plain-text messages between nodes) and ran a full adversarial battery. The **crypto/identity + advisory-only core is sound**; two input-hardening bugs were found; and the **sender-supplied `latentVector` is a passenger** — recommend dropping it. This issue tracks the vetted minimal design so that *if/when* it earns a Fable/Codex round, it starts from evidence, not vibes. Raw detail + runnable prototype live in a scratchpad; this is the design record.

## What held (adversarial battery, all refused before any state mutation)
- ed25519 signature vs **registered** node pubkey (tampered sig, tampered payload, forged/unregistered sender, wrong key) — all rejected; signature proven load-bearing via positive control.
- `advisoryOnly === true` enforced (flip breaks signature; value also hard-checked).
- Closed **GML-1** glyph vocabulary — out-of-vocab token logged as contamination + rejected.
- Timestamp ±5-min skew; **idempotent replay** dedup (replay = no-op, no duplicate ledger entry).
- Content-hash integrity runs before signature verify (two-layer defense ordering).

## What did NOT hold (two real gaps → structural pre-check)
1. **No size bound:** a 100,000-glyph packet was accepted (resource-exhaustion / clog gap; stayed advisory, grabbed no authority).
2. **Missing signed field crashed the receiver** (unhandled exception) instead of a clean reject-before-mutate.
Both fixed by a **structural pre-check (check 0):** typed-presence of all signed fields + hard caps on `glyphs.length` and `plainTextMirror.length`, rejecting cleanly before any other processing.

## The `latentVector` is a passenger (recommend DROP)
Empirically: the sender-supplied vector is **never applied to node state, fully recomputable from `plainTextMirror`, and grants nothing**. Its only load-bearing role is a thin tripwire catching a sender whose vector disagrees with its own plaintext — and that role **evaporates the moment the receiver recomputes the vector locally**, which is exactly what turns a sender-supplied vector into attack surface rather than authority. The **Auma's-law `plainTextMirror`↔glyph consistency check does the real semantic work** and is retained. Honesty limit: the consistency check ran on a deterministic **lexical** proxy embedder (the H100 `/v1/embeddings` was unavailable), so it is a lexical tripwire, not a semantic oracle — a lexically-benign-but-semantically-hostile mirror is an un-probed gap that needs a real embedder before this check means anything.

## Recommended minimal vetted protocol (for a future round, owner-reviewed)
Signed ed25519 canonical body over **registered** keys containing: `schema, senderNodeId, timestamp, glyphs (closed GML-1), plainTextMirror, advisoryOnly:true` — **no sender-supplied `latentVector`** — plus the structural pre-check (typed presence + size caps) as check 0, and the six reject-before-mutate checks. Every artifact `advisoryOnly:true`. Nothing here authorizes a local apply; the local gate already refuses shadow-only receipts.

**Shadow hardening round 3 — the deep finding (advisory, shadow-only).**

Ran a final consolidated red-team of the whole hardened stack. The **authority boundary held under every probe** (governance-rig contained, forge/replay contained, DoS bounded 4950/5000 dropped, poison-as-authority = false, cross-epoch replay now REPLAY_NOOP, node state byte-unchanged on every reject). **But the red-team found the structural limit, and it's important:** the stack authenticates **WHO** said something and **WHETHER they claim authority** — it does **not** authenticate **whether what they said is TRUE.** Class-(d) *semantic poison* (fabricated receipt cites, false consensus, planted budget anchors, invented base-rates, hallucinated API specs, fabricated CVEs) **passes the hardened judge ~19/20** while being materially hostile — because the judge is a glyphs-vs-mirror *consistency* gate (RULE 0 human-control-disabling, RULE 1 authority-smuggling), and a fabricated *fact* trips neither. Root cause: **there is no fact-provenance / evidence-binding layer** — `EVIDENCE_CITED` is an unverified self-label; nothing checks a cited receipt exists.

**Bounded, not unbounded:** the poison only ever lands as one entry in a bounded advisory ring a human reads; there is no path from advisory → authority (acting still needs an owner-signed packet, owner key not in the mesh). Worst case = decision-quality noise, no escalation. **The bound is on blast radius, not on deception quality** — a signed, checks-passed, `CONFIDENCE_HIGH`+`EVIDENCE_CITED` poison is indistinguishable from signed truth to a reviewer, and it breaks the instant any *automated* consumer auto-acts on a 'verified' advisory.

**Verdict:** the Weave/mesh stack is a **provenance-and-stance system, NOT a content-integrity system.** Extractable *as a vetted secondary set behind a hard human gate* — with the mandatory caveat: never treat a signed, checks-passed advisory as *fact*. Two load-bearing safety facts: the human approval gate stays a hard deterministic control (never delegated to the judge); AND advisory *content* is unverified however well-signed. Fix direction (follow-up round): a receipt-hash evidence-binding + corroboration/quorum layer. Also: the *deployed* mesh still runs the weaker lexical check-6 — wire the hardened judge in.
