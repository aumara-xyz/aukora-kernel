Concern:
readSignedPromotionReceiptFromFile(filePath) or equivalent receipt readers may read arbitrary filesystem paths and then validate JSON. Shape validation is good, but the filesystem read itself should be scoped.

Goal:
Receipt readers used by server/workbench commands should only read from trusted receipt/proposal locations.

Allowed locations sketch:
- ~/.aukora-symbiote/aumlok/receipts/
- ~/.aukora-symbiote/aumlok/pending-proposals/
- explicit temp signed receipt pattern under os.tmpdir() for tests/rehearsal

Required checks:
- realpathSync
- no symlink escape
- prefix check with path separator boundary
- max file size before JSON parse
- exact schema allow-list
- clear refusal reason

Acceptance tests:
- arbitrary /tmp JSON outside allowed pattern refused
- symlink into allowed dir pointing outside refused
- oversized file refused before parse
- malformed JSON and extra keys fail closed
- legitimate receipt in allowed dir still verifies.
