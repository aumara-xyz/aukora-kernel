## Scope
Track Guardian's future brick for **governed absorption of proactive/autonomous capability classes**.

This is planned, not shipped. It comes late, after the core inside-out loop is reliable.

## Why this matters
Hermes/Open-Claw/Odysseus-class systems are useful because they can act proactively. The risky capability class is not just tool use; it is unattended triggering:
- scheduled / cron execution;
- inbound webhook triggers;
- outbound messaging / notification;
- background loops that can decide to act while the owner is not actively prompting.

## Hard invariant
These capabilities are admitted only as typed adapters. Every triggered effect becomes a mediated event through the same chokepoint as a manual tool call.

A timer firing, webhook arriving, or outbound message about to send carries no intrinsic authority. It can observe, draft, queue, or propose according to its adapter type; it cannot authorize itself.

## Sequencing
Build last. Hermes specifically remains PARKED_HIGH_RISK outside direct wiring. It can be unparked only by becoming a conforming adapter with tests, not by being wired in directly because it is useful.

## Minimum acceptance before any adapter goes live
- Typed adapter schema for the trigger/event/effect.
- Sandbox heartbeat test.
- Provenance receipt for every triggered event and proposed effect.
- Proof of no chokepoint bypass.
- Rollback/replay story for any promoted change.
- Tests showing schedule/webhook/message events cannot authorize, sign, mutate live state, or send externally without the governed path.
