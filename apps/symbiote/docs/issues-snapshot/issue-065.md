Useful ideas to preserve:
- BFS/state-space exploration with frame/state hashing.
- Visited-state tracking so the solver does not revisit identical states.
- Progressive transfer: solved level 1 can seed level 2.
- Dead-end detection: stop or change primitives when most paths fail.
- Deterministic seeding so runs are comparable.
- Receipted solve attempts: puzzle id, rules hash, solver config, path, result, elapsed budget.
