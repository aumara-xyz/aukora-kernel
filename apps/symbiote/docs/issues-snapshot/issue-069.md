## Body

Auma ACCL v1.1 addendum. Sequence: C first.

Goal:
Collapse failed-draft cost by making a single owner intent run a bounded sandbox loop: draft -> test/typecheck/scan -> feed actual failures back -> redraft -> rerun, until green or exhausted.

Why now:
This is the biggest multiplier on every future inside-out build round and adds no new authority surface. It reduces human prompt churn without weakening AUMLOK.

Required behavior:
- Max attempts K, start K=5, plus hard wall-clock cap.
- Every attempt happens only in sandbox.
- Green exit produces diff, VerifyReport, attempt history, and signing handoff.
- Exhausted exit produces best diagnosis, failed checks, attempts tried, and no apply path.
- Readiness-ladder tests are always in the gate set.
- A draft that weakens safety/ladder tests is refused even if the narrow failing test turns green.

Acceptance tests:
- Known fixable broken draft converges to green within K.
- Known unfixable draft exits exhausted with useful diagnosis.
- Attempt touching live repo before signature fails.
- Attempt weakening readiness/honesty tests is rejected.
- Attempt history is attached to VerifyReport but grants no authority.

Non-goals:
- No autonomous apply.
- No signing/key handling by Auma.
- No git push from the sandbox loop itself.
