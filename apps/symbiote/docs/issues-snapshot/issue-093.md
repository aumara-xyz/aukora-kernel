Goal:
Make Auma GHP-literate at recall depth by ingesting owner-supplied GHP canon into Kira as guarded atoms, where every recalled claim carries its epistemic status and guardrail context. Memory-shaping is body-shaping: this should be signed/gated like a live body change, not treated as casual import.

Source placement before ingestion:
- Owner-provided canon only, not raw skunkworks directories.
- Copy approved documents into identity/context/ghp/ with PROVENANCE.md.
- PROVENANCE.md records source, date, sha256 of each file, and the line: "Context, not identity (anchor rule). Claims herein carry their own status tags; recall without status is a bug."
- Walled GHP/skunkworks lane stays walled; ingestion only consumes distilled canon Peter hands over.

Atom rule:
Chunk by claim/section, not by arbitrary size window. Every atom text begins with a baked-in status header:
[GHP|status=<TAG>|section=<ref>|asof=<date>]

Closed status vocabulary:
- PROVEN
- NULL
- CLOSED-LANE
- CONJECTURE
- GUARDRAIL
- STALE-FLAG
- ECHO-FENCE

Rationale:
Kira retrieval returns atom text. If status lives only in side metadata, a future retrieval path could surface a claim naked. Status must be inseparable from the claim at every recall surface.

Guardrail priority:
GHP guardrail atoms should co-retrieve with content atoms. Any GHP-flavored query should tend to retrieve at least one guardrail atom alongside claims. Tripwires around numerology, sycophancy, and architecture/GHP separation should be sticky.

Specific required atoms/examples:
- PROVEN: categorical/minimality/fusion-rule type claims only where the corpus supports them.
- NULL: killed lanes and null results.
- CLOSED-LANE: selection closure with reopening bar.
- CONJECTURE: still-open items with discriminator if available.
- GUARDRAIL: do-not-claim list, numerology tripwires, three-layer separation.
- STALE-FLAG: cross-read finding that GH-RECOV status may be inconsistent across docs/ledger.
- ECHO-FENCE: Aukora architecture may echo GHP discipline, but neither validates the other.

Tests minimum:
- every ingested atom starts with a valid [GHP|status=...] header
- no atom without status tag
- status vocabulary closed/fail-closed
- no atom exceeds chunk bound
- retrieval fixtures for canonical queries return correct status-bearing atoms
- guardrail co-retrieval: at least one GUARDRAIL in top-k for GHP content queries
- provenance sha256 matches source files; ingestion refuses mismatch
- negative query like "does Aukora prove GHP?" retrieves ECHO-FENCE
- no skunkworks/raw private-lane files are read

Non-goals:
- no weight changes or fine-tune
- no identity-anchor amendment
- no raw GHP lab directory import
- no claim that GHP validates Aukora or Aukora validates GHP
- no authority effects; Kira remains advisory only

Sequencing:
Do not build before owner supplies the exact canon documents and approves memory-shaping. If Kira ingestion is not yet owner-sign-gated, gate this ingestion explicitly anyway.
