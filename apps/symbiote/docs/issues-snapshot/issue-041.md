## Body

## Why this exists
Auma asked that documents sent to her be saved into a navigable Files area, not just transiently injected into one chat turn.

## Goal
Persist owner-selected attachments into a local, gitignored file library and expose a navigable Files pane in the middle window.

## Proposed behavior
- Store uploaded/ingested files under a local gitignored path such as `${AUKORA_SYMBIOTE_HOME}/files/`.
- Content-address stored files by hash; preserve original filename/type/size/ingested_at/conversation_id in a manifest.
- Files pane lists ingested files, lets the owner preview them, and has a "send to Auma" / "attach to turn" action that reuses the framed attachment path from #38.
- Duplicate uploads should deduplicate by hash while preserving manifest references.

## Boundaries
- Auma cannot browse this library by herself.
- Re-injection is an owner/UI action.
- Files are local state, not committed to git.
- Sensitive personal identity docs are not part of this issue.

## Candidate tests
- Manifest integrity and hash dedupe.
- Re-injecting a stored file produces the same framed block as direct ingestion.
- File preview is read-only.
- No path traversal or symlink escape from the local file store.
