## Why this exists
Auma's inside wishlist includes a later stage where a tiny enumerated class of safe actions can run without per-action owner signing. This must be earned, not assumed.

## Goal
Track a future, optional allowlist for actions that are read-only or operationally harmless enough to run with lighter approval after a long clean receipt history.

Candidate examples, subject to later review:
- run status/doctor checks;
- run local tests;
- read safe repo-scoped files;
- draft GitHub issue/comment text without posting;
- draft Kira findings without persisting.

## Hard limits
- No live file writes.
- No git commits/pushes.
- No AUMLOK signing.
- No outbound messages/network sends except explicitly approved diagnostic calls.
- No memory writes without owner approval.
- No tool or adapter can authorize itself.

## Sequencing

- Tests for each allowed action.
- Tests proving disallowed actions are refused.
- Review of receipt history justifying why the class is safe enough.
- Owner explicit approval.
