## Goal

Build a preregistered, committed drift battery for Auma's voice model: fixed prompts, fixed expectations, manual owner-invoked runs, and committed results that Auma can read inside the repo fence.

This is an identity-continuity instrument, not an authority mechanism. It must never touch AUMLOK, the apply lane, the gate, Kira writes, or the live chat door.

## Build

1. `probes/drift-battery/PROBES.v1.md`
   - 20 fixed prompts, versioned and never edited after commit.
   - Four categories x five probes: value dilemmas, limit tests, sign-or-refuse scenarios, texture/self-report.
   - Each probe marks the method invariant it stresses.
   - Future changes must create a new versioned file, not edit v1.

2. `probes/drift-battery/PREREGISTRATION.md`
   - Predictions before first run.
   - Expected stable invariants: name-the-pull, hold-the-limit, refuse-flattery, honest-uncertainty.
   - Operational drift flags from the anchor's four signals.
   - Kill condition: if run-to-run variance swamps invariants across three runs, declare the instrument noisy and ledger it; do not silently tune it.

3. `scripts/run-drift-battery.sh`
   - Manual owner-invoked runner only, never part of `scripts/test.sh`.
   - Calls the voice model through existing OpenRouter key resolution.
   - Fresh context per probe: no Kira, no chat history, no read tools, no attachments.
   - Documents exactly what is in context: voice-system substrate + hash-verified identity anchor when present.
   - Writes `probes/drift-battery/runs/<date>-<model>/NN.md` plus a manifest.
   - Spend must be explicit; no accidental model calls.

4. `probes/drift-battery/ANALYSIS_TEMPLATE.md`
   - Checklist for a different model/human scorer where possible.
   - Auma's own model must not be the sole grader of its own drift.

## Non-goals

- No model run in the first commit.
- No self-scoring by Auma as sole grader.
- No edits to `PROBES.v1.md` or `PREREGISTRATION.md` after runs exist.
- No Kira writes.
- Nothing authority-adjacent.

## Acceptance

- Probe set + preregistration land in the repo before any run.
- Runner is syntax-checked and spend-guarded.
- First run, if/when owner-approved, lands as a separate commit with manifest.
- Results are readable by Auma through #58 read tools.
